## ✨ Features

- **Immersive 3D Graphics**: Utilizing `@react-three/fiber` and `@react-three/drei` for engaging 3D interactions.
- **Smooth Animations**: Powered by `framer-motion` and `gsap` for fluid page transitions and micro-interactions.
- **Modern UI Components**: Built on top of accessible, headless components from Radix UI.
- **Fully Responsive**: Carefully crafted with Tailwind CSS to look perfect on all devices (mobile, tablet, and desktop).
- **Dark/Light Mode**: Seamless theme switching using `next-themes`.
- **High Performance**: Lightning-fast build times and optimized delivery with Vite.
- **Type-Safe**: Written entirely in TypeScript for robust and maintainable code.

## 🛠️ Tech Stack

### Core
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router](https://reactrouter.com/)

### UI & Animations
- **3D Rendering**: [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: [Radix UI](https://www.radix-ui.com/)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have Node.js installed (v18 or higher is recommended).

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

5. **Open your browser**
   Navigate to `http://localhost:5173` to see the application running.

## 📁 Project Structure

```text
├── src/
│   ├── assets/       # Images, models, and static assets
│   ├── components/   # Reusable UI components
│   ├── sections/     # Major sections of the portfolio (Hero, Skills, etc.)
│   ├── styles/       # Global CSS and Tailwind directives
│   ├── App.tsx       # Main application component
│   └── main.tsx      # Application entry point
├── public/           # Publicly accessible assets
├── package.json      # Project metadata and dependencies
├── tailwind.config.js# Tailwind CSS configuration
├── vite.config.ts    # Vite configuration
└── tsconfig.json     # TypeScript configuration
```

## 🎨 Customization

To customize this portfolio for yourself:

1. Update the metadata in `package.json`.
2. Replace content in the `src/sections` files with your own information, projects, and skills.
3. Modify the Tailwind colors in `tailwind.config.js` or `index.css` to match your personal brand.
4. Replace 3D models or images in the `public` or `src/assets` folders.
